# Error taxonomy

## Critical educational errors

The planned primary endpoint records whether an output contains at least one of the following:

| Error | Meaning |
| --- | --- |
| Wrong lexical sense | The selected form expresses a different meaning from the intended concept. |
| Non-equivalent translation | Source and target fail to preserve intended information or relation. |
| Invalid target construction | The target realization is ungrammatical or unsuitable in the required construction. |
| Ambiguous expected answer | The task does not provide enough information to determine an acceptable answer fairly. |
| Explicit constraint violation | The output conflicts with a stated form, register, construction, or avoidance requirement. |

## Diagnostic categories

The methodology may also record non-primary diagnostic categories: missing provenance, malformed structure, unresolved register, unsupported certainty, incomplete evidence, or validator disagreement. These describe why output may need repair or review; they are not automatically critical educational errors.

## Use in evaluation

The confirmatory protocol will fix category definitions and adjudication rules before execution. Categories make failure analysis inspectable; they do not imply automated labels are final linguistic judgments.
